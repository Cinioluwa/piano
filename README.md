# Synthwave Piano

This is a **Synthwave-style piano** built with HTML, CSS, and JavaScript. It allows users to interact with a virtual piano using mouse clicks or keyboard keys, simulating a musical experience with retro aesthetics and animation effects.

## Features

- **Synthwave Aesthetic**: Retro neon lights and animations for a cool, futuristic look.
- **Interactive Piano Keys**: Clickable keys with real-time sound playback.
- **Keyboard Integration**: Use your computer's keyboard to play piano notes.
- **Audio Feedback**: Audio files are played when the keys are pressed.
- **Responsive Design**: Works across various screen sizes.

## Installation

1. **Clone or Download** the repository:
    ```bash
    git clone https://github.com/Cinioluwa/piano.git
    ```

2. Open the `index.html` file in a browser to start playing the piano.

## Technologies Used

- **HTML**: For structure and layout.
- **CSS**: For styling, including animations and responsive design.
- **JavaScript**: For handling interactivity and playing sounds.
- **Audio Files**: Each piano note is associated with an individual sound file.

## Usage

- **Mouse Interaction**: Click any key on the piano to play the corresponding note.
- **Keyboard Interaction**: Press keys on your keyboard (e.g., 'D', 'E', 'R') to play the notes.
  
Refer to the key mapping in the JavaScript code to see how keys correspond to piano notes.
